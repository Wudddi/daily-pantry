# Project submission summary

Repository: https://github.com/Wudddi/daily-pantry

## Short description

Daily Pantry is an English-language personal food inventory, meal-planning and nutrition app with a Model Context Protocol (MCP) interface. It gives an AI assistant current inventory, durable preferences, freshness information and familiar meal patterns. People can edit daily meals, adjust an entire recipe to half or custom servings, move uneaten portions between meals, and add inventory foods directly. Planned menus, actual intake, personal reminders, supplement use and stock accounting remain separate to prevent duplicate deductions.

## Additional project information

This is an actively used personal project, with a public source copy containing fictional demonstration data. The English interface, assistant-tool instructions, documentation, tests and change history support review and further development. Existing original-language user records and legacy wire keys remain backward compatible; production inventory, health records, private hosting identity and credentials are excluded from the public repository.

The implementation was developed iteratively with Codex/ChatGPT assistance. This statement does not claim previous Claude Code development or acceptance into any external program.
